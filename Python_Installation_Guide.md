# Python Installation Guide for Beginners

## Introduction

Python is one of the programming languages I enjoy
working with. It is widely used in web development,
data analysis, automation and artificial intelligence.

In this guide, I will explain how to install Python
on a Windows computer and run your first program.

## Step 1: Download Python

1. Open your web browser.
2. Visit https://www.python.org/downloads/
3. Click on the Download Python button.
4. Wait for the installer to download.

## Step 2: Install Python

1. Open the downloaded installer.
2. Select the option "Add Python to PATH".
3. Click on Install Now.
4. Wait until the installation is completed.
5. Close the installer after successful installation.

Note: Adding Python to PATH makes it easier to run
Python commands directly from the terminal.

## Step 3: Check Python Installation

Now we need to check whether Python is installed
correctly.

1. Open Command Prompt.
2. Type the following command:

   py --version

3. Press Enter.

If Python is installed correctly, the terminal
will display the installed Python version.

## Step 4: Create Your First Python Program

1. Open Notepad or any code editor.
2. Write the following code:

   print("Hello, World!")

3. Save the file as hello.py.
4. Open Command Prompt in the folder where you
   saved the file.
5. Run this command:

   py hello.py

You should see:

Hello, World!

Congratulations! Your first Python program
is running successfully.

## Common Problems and Solutions

### Problem 1: Python is not recognized

If the terminal says Python is not recognized,
check whether Python was added to PATH.

You can also try using:

py --version

### Problem 2: Installation is not completed

Try downloading the installer again from the
official Python website and run it.

### Problem 3: Program is not running

Check the following:

- Make sure the file ends with .py.
- Check whether you are in the correct folder.
- Check your Python code for spelling mistakes.

## Conclusion

Installing Python is the first step towards
learning programming.

Once Python is installed, you can start practising
basic programs and gradually move towards topics
like data analysis, machine learning and automation.

I hope this guide helps beginners get started
with Python.
